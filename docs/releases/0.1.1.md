# Voxriva 0.1.1 prerelease

This release adds versioned application and MCP container distributions for
**linux/amd64**, a small operator download, and the independently packaged
Python delivery SDK. There are no database migrations or Delivery v1 contract
changes relative to 0.1.0.

- Application: `ghcr.io/alexivanchyk/voxriva:0.1.1`
- MCP: `ghcr.io/alexivanchyk/voxriva-mcp:0.1.1`
- SDK: `python -m pip install voxriva-sdk==0.1.1` (Python 3.10+)

Download `Voxriva-0.1.1-operator.tar.gz` and `OPERATOR-SHA256SUMS` from this
release, verify the checksum, extract, then run `python3 scripts/example.py`.
The launcher pulls the ready image and verifies an email in a local Mailpit inbox.
No checkout or compilation is required. See the
[quickstart](https://alexivanchyk.github.io/Voxriva/quickstart/),
[SDK examples](https://alexivanchyk.github.io/Voxriva/journeys/integrate/) and
[self-hosting guide](https://alexivanchyk.github.io/Voxriva/self-hosting/).

The tested candidate image archives are promoted without rebuilding. Attached
`release.json` and `published-digests.json` identify source revision, candidate
run, image IDs and registry digests. SDK wheel and source distribution are built
once, tested in clean Python 3.10/3.13 environments, then promoted through
TestPyPI to PyPI using those same files.

Own code is MIT; bundled dependencies retain their upstream licenses. Container
notice/source inventories are included under `/app/release-metadata/third-party`.
Redis 7.4.7 is pulled separately under its upstream RSALv2/SSPLv1 terms; the
application license does not relicense that image. The JSON Schema dependency
now uses jsonschema's supported `format-nongpl` extra, retaining URI/IRI checking
without `rfc3987`. See
[third-party notices](https://github.com/AlexIvanchyk/Voxriva/blob/v0.1.1/THIRD_PARTY_NOTICES.md).

This remains a prerelease: native ARM64, measured capacity guarantees, HA and a
production support SLA are not provided. Actual package availability and final
consumer checks are tracked in
[release status](https://alexivanchyk.github.io/Voxriva/release-status/).
